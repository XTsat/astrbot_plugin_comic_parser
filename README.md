## 功能

- **贴链接就能下**：`/comic <作品链接>` 自动识别站点并下载整本，不用记每个平台各自的命令
- **按 ID 直接下载**：给出漫画 ID 或链接即可下载整本
- **统一打包**：下载完成后统一打包为 ZIP 压缩包、PDF 文档或纵向长图，也可以只保存到本地不发送
- **统一加密**：全局只有一个打包密码，ZIP 用 AES 加密、PDF 用 AES-256 加密；设置了密码但没有安装加密依赖时会直接报错，不会悄悄发出未加密的文件
- **进度可见**：默认在命令消息上贴表情（❤️ 下载中 → OK 完成 / 🔨 失败），贴上了就不再发「开始下载」这类消息；也可切换为文本进度或关闭
- **结果说明可关**：下载完成的摘要（标题 / 作者 / 图片数 / 耗时）可以关掉，只发文件
- **会话管控**：白名单 / 黑名单决定哪些会话能用，防抖避免同一本被反复下载
- **先挑最快的域名**：多个站点域名 / 图床时，下载前会同时测一遍（响应时间 + 小样本下载速度），把最快的排到最前面，慢的不再让你干等；测速结果会缓存一段时间，不会每本都重测
- **任务排队**：全局并发上限 + 整本超时与重试，多人同时使用时不会把机器拖垮
- **自动清理**：文件发出后删除本地临时文件，长期使用也不占满磁盘
- **下载完自动进群文件**：可开启「下载后上传到群文件」，成品直接传进当前群的群文件（可指定文件夹；群里没有这个文件夹时，机器人是管理员就自己建一个，建不了就传根目录）；传成功后群里本来就会出现这条文件消息，聊天里不再重复发一遍，传不上去才改为直接发文件

## 指令

| 指令 | 权限 | 说明 |
|------|------|------|
| `/comic <作品链接>` | 全部（受白名单/黑名单约束） | 贴作品页的完整链接，自动识别站点并下载整本（支持下面所有渠道） |
| `/jm <ID 或链接>`（全称 `/jmcomic`） | 全部（受白名单/黑名单约束） | 下载整本 JM 漫画 |
| `/nh <ID 或链接>`（全称 `/nhentai`） | 全部（受白名单/黑名单约束） | 下载整本 nhentai 作品 |
| `/pica <ID 或链接>`（全称 `/picacg`） | 全部（受白名单/黑名单约束） | 下载整本哔咔漫画（需在渠道配置里填哔咔账号） |
| `/hm <ID 或链接>`（全称 `/hanime1`，也可 `/ha`、`/hanime`） | 全部（受白名单/黑名单约束） | 下载整本 Hanime1 漫画 |
| `/ssmh <ID 或链接>`（全称 `/wnacg`，也可 `/wn`） | 全部（受白名单/黑名单约束） | 下载整本紳士漫畫作品 |
| `/漫画帮助` | 全部 | 查看当前可用渠道、打包格式、密码与进度提示设置 |

> 只想下某一本时，贴链接给 `/comic` 最省事；只知道 ID（或链接不是作品页）时，用对应渠道的命令。
> 渠道命令也不限定站点：`/jm` 后面贴 nhentai 链接会下 nhentai 那本，实际走的站点写在下载摘要里。
> 缩写（`/jm`、`/nh`、`/pica`、`/hm`、`/ssmh`）是日常用法，插件提示里展示的也是缩写；站点全称同样可以敲，两种写法效果一样。

/comic https://hanime1.me/comic/100445
/comic https://www.wnacg.site/photos-index-aid-401500.html
/jm 123456
/jm https://18comic.vip/album/123456/
/nh 123456
/nh https://nhentai.net/g/123456/
/pica 5f1e2d3c4b5a69788796a5b4
/hm 100445
/hm https://hanime1.me/comic/100445
/ssmh 401500
/ssmh https://www.wnacg.site/photos-index-aid-401500.html

## 其它

### 常见问题

**为什么开了「下载后上传到群文件」，聊天里却还是收到了文件？** 两种情况会退回「直接发文件」：一是这次上传失败（原因会写在消息里），二是当前不是群聊下载或协议端不支持群文件上传。上传失败常见的原因是运行环境读不到这个文件——插件和协议端不在同一台机器、或不在同一份挂载目录里时，协议端拿不到插件的临时路径；另外机器人账号没有上传权限也会失败。

**为什么文件进了群文件根目录，而不是配置的那个文件夹？** 群里没有这个文件夹、又没能新建时就是这样：新建群文件夹需要机器人是群管理员或群主，普通群成员建不了，插件会照样把文件传到根目录而不是让整次下载白费。把机器人设成管理员，或者手动在群文件里建好这个文件夹即可。
